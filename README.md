# RevolutionaryUtenaMusicPlayer
4 months into learning to code, my first 'from scratch' coding project, in PyQt5. 
Doesn't deal with song metadeta, just has some functionality to play music. Plays gifs from the anime alongside, also has random msgs from me.
To make it work, you'll need a local folder with only mp3 files, remember to add the path whereever a string says ".../Music"  

The screenshots folder has images of what it would look like if it works.
